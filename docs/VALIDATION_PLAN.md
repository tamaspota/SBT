# Verification plan — planning only

1. **Bench**: calibrated resistors / conductance standards, repeatability, linearity, noise floor, drift, warm-up and supply sensitivity.
2. **Contact**: electrode geometry/material, pressure, placement and skin compatibility; test motion-induced artifacts and quality flags.
3. **Safety**: measurement current limits, leakage, battery safeguards, isolation during charging, ESD/EMC; engineering review before human testing.
4. **Communications**: BLE loss, reconnection, latency, range, iOS and Android permissions, low battery and data integrity.
5. **Usability**: handheld vs wrist vs glove fitting and maintenance.
6. **Comparator**: compare raw GSR physical readings to a reference measurement device; do not infer ZYTO virtual wellness items from GSR without independent scientific validation.

Success thresholds must be specified in a signed test plan before a pass/fail claim.
